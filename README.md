*Black Jack

This was my final project for my Intro to Computer Science class a few years ago.

The real assignment was to make a CLI Black Jack game (which I did) but I had been
interested in game development and wanted to give it a shot so I taught myself how
to use Pygame, made a load of pixel assets and got to work.

If you want to run it, just clone the repository and then open the file marked 0black_jack_game_file.py
and run it, make sure Pygame is installed. I will evetually probably put this on my website, I will link that
when I get that done! (Right now I am busy with other projects and applying for jobs!)
